# Workstation

**Your Friendly Work Companion for Developers**

Workstation is a local-first desktop workspace for developers who want to keep work resources, technical notes, project progress, screenshots, and operational records in one organized place.

It is designed to help you find what you need quickly, preserve context before interruptions, and continue work without rebuilding your mental map from scratch.

## What Workstation Can Help You Do

### Find Information Quickly

- Search across saved links, folders, notes, knowledge entries, screenshots, projects, and work records.
- Use keyword search when you remember only part of a name, path, purpose, or note.
- Use keyboard navigation to move through search results and open the selected item.
- Switch between list, grid, and spatial navigation views.

### Save Useful Resources

- Save web links and frequently used local folders.
- Store accounts, key-value information, and sensitive reference data in protected local storage.
- Keep server operation records and database operation records for later review and reuse.
- Record paths, commands, links, notes, and supporting details in a structured format.
- Associate resources with projects, progress nodes, knowledge entries, screenshots, and work scenes.

### Preserve Work Context

- Save work scenes before leaving a task.
- Record the current task, progress, next step, related applications, folders, links, and screenshots.
- Return to a saved scene later and continue from the recorded next step.
- Keep multiple screenshots, folders, and links with the same work scene.

### Organize Projects and Progress

- Build project hierarchies and implementation checklists.
- Create progress chains with lanes, nodes, connections, statuses, owners, due dates, results, and blockers.
- Use a visual canvas to organize work in a way that matches your real process.
- Attach resources directly to individual progress nodes.
- Review progress updates and generate structured progress reports.
- Open a focused topic workspace for a specific progress chain.

### Build a Personal Knowledge Base

- Create a tree-structured knowledge base.
- Add notes, images, links, tags, and supporting materials to knowledge entries.
- Search and browse knowledge by topic, hierarchy, or keyword.
- Export a selected knowledge tree as a portable data package.
- Import compatible data packages into another Workstation knowledge tree.

### Capture and Index Screenshots

- Capture screenshots from selected screens or windows.
- Add annotations, names, notes, and visual marks.
- Reopen the original source when available.
- Add follow-up annotations without overwriting previous notes.
- Use screenshot indexing and sketch-based lookup to find visual records more easily.

### Review Conversations and Questions

- Import or enter original questions for structured review.
- Select text to create subquestions.
- Add answers, notes, and follow-up content.
- Append new content without rewriting existing annotations.
- Keep discussion history organized for later reference.

### Track Work Activity and Habits

- Review actions started from inside the application, such as opening, copying, and viewing resources.
- Reopen frequently used resources from activity records.
- Pin, pause, delete, or review activity groups.
- Build habit chains from repeated workflows.
- Use saved action chains to return to familiar working sequences.

### Import Structured Data Safely

- Use fixed CSV and JSON examples as import references.
- Import supported records in batches instead of entering them one at a time.
- Use predefined field structures to reduce malformed or unexpected input.
- Review imported data before relying on it in daily work.

### Customize the Workspace

- Choose from multiple visual themes.
- Customize tab names, order, icons, startup behavior, and navigation preferences.
- Use Chinese, English, German, French, Spanish, Italian, Japanese, Korean, or Traditional Chinese.
- Configure the startup welcome screen and personal workspace preferences.
- Use keyboard shortcuts, quick switching, and global search for faster navigation.

### Use Spatial Views

Workstation includes optional spatial navigation views for users who prefer visual memory and location-based navigation.

- **Cabinet View** organizes features as objects in a visual cabinet.
- **Floor View** organizes features across multiple functional floors.
- Navigate through large, camera-facing labels designed for fast recognition.
- Use static previews in Settings before selecting a spatial view, so 3D rendering does not start unnecessarily.
- Install supported spatial view packages independently.
- Activate individual spatial views with offline, device-bound activation codes.

Spatial views are optional. List and grid views remain available without activation.

### Plugins and Extensibility

- Use built-in system plugins for features such as batch import and license record management.
- Manage installed plugins from the application.
- Keep plugin capabilities separated from the core workspace.
- Allow experimental plugins to evolve independently while keeping the main workspace stable.

## Privacy and Local Data

Workstation is designed as a local-first application.

- Your work records are intended to remain on your device by default.
- The application does not read your keyboard in the background.
- The application does not automatically capture screenshots in the background.
- The application does not automatically upload your local business data to the author’s server.
- Plugins do not receive network access by default.

Please do not store information involving personal safety, life safety, major financial security, classified material, or other highly sensitive information. No software can guarantee that data will never be lost, damaged, or exposed.

Before deleting application data, reinstalling the operating system, or changing the original environment, please make sure you understand your backup and recovery options. Encrypted local data may not be recoverable if the original environment is no longer available.

## Backups and Recovery

Please keep regular backups of important work.

Workstation is designed to keep the application shell and workspace features independent where possible, but no software can fully eliminate the risk of device failure, accidental deletion, operating system damage, or unexpected data loss.
